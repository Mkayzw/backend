# 4.3.1 Use-Case Diagram

This version is kept simple for a white page and printing. The Mermaid below uses a flowchart layout so it renders more reliably than Mermaid's newer `usecase` syntax.

```mermaid
flowchart LR
    Patient[Patient]
    Clinician[Clinician]
    Admin[Administrator]

    subgraph Auth["Authentication and Access"]
        UC1(Register and Login)
        UC2(Access Role-Based Pages)
    end

    subgraph PatientFunctions["Patient Functions"]
        UC3(Submit Symptom Report)
        UC4(View Own Reports)
        UC5(View Current Risk and Trend)
        UC6(View Personal Alerts)
    end

    subgraph ClinicianFunctions["Clinician Functions"]
        UC7(View Assigned Patients)
        UC8(Review Patient Reports)
        UC9(View Risk and Trend Status)
        UC10(View and Mark Alerts)
    end

    subgraph AdminFunctions["Administrator Functions"]
        UC11(Manage Users)
        UC12(Manage Assignments)
        UC13(View System Metrics)
    end

    subgraph SystemFunctions["System Intelligence Functions"]
        UC14(Classify Risk)
        UC15(Analyze Trend)
        UC16(Generate Alerts)
        UC17(Store Reports and Status)
    end

    Patient --> UC1
    Patient --> UC2
    Patient --> UC3
    Patient --> UC4
    Patient --> UC5
    Patient --> UC6

    Clinician --> UC1
    Clinician --> UC2
    Clinician --> UC7
    Clinician --> UC8
    Clinician --> UC9
    Clinician --> UC10

    Admin --> UC1
    Admin --> UC2
    Admin --> UC11
    Admin --> UC12
    Admin --> UC13

    UC3 --> UC14
    UC3 --> UC15
    UC14 --> UC16
    UC15 --> UC16
    UC3 --> UC17
    UC16 --> UC6
    UC16 --> UC10
```

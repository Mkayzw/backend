# 4.4.5 Interface Design

This file contains three simple interface design diagrams based on the actual frontend structure in the project.

## 4.4.5.1 Menu Design

```mermaid
flowchart LR
    Login[Login Page]
    Signup[Signup Page]

    Login --> Auth{Authenticated User}
    Signup --> Auth

    Auth -->|Patient| PatientMenu
    Auth -->|Clinician| ClinicianMenu
    Auth -->|Admin| AdminMenu

    subgraph PatientMenu["Patient Navigation"]
        P1[Dashboard]
        P2[Report Symptoms]
        P3[My Clinicians]
        P4[My Reports]
        P5[Profile]
    end

    subgraph ClinicianMenu["Clinician Navigation"]
        C1[Dashboard]
        C2[My Patients]
        C3[Alerts]
        C4[Trend Analysis]
    end

    subgraph AdminMenu["Administrator Navigation"]
        A1[Dashboard]
        A2[Users]
        A3[Patients]
        A4[Clinicians]
        A5[Assignments]
        A6[Alerts]
        A7[System Metrics]
    end
```

## 4.4.5.2 Input Design

```mermaid
flowchart TD
    A[User opens a form]
    B{Form type}

    C[Authentication form<br/>email, password, role data]
    D[Symptom report form<br/>symptoms, severity, duration,<br/>frequency, vitals, notes]
    E[Profile or assignment form<br/>contact data, chronic conditions,<br/>care context, reason]

    F[Frontend validation]
    G[Protected API request]
    H[Backend schema validation]
    I{Valid input?}
    J[Save to database]
    K[Return validation error]
    L[Show success message and refresh page data]

    A --> B
    B -->|Login or Signup| C
    B -->|Patient reporting| D
    B -->|Profile or admin action| E

    C --> F
    D --> F
    E --> F
    F --> G
    G --> H
    H --> I
    I -->|Yes| J
    I -->|No| K
    J --> L
    K --> L
```

# 4.4.1 Context Diagram and DFD Diagram

This file contains two diagrams: a context diagram and a simple data flow diagram. Both are arranged to stay readable on a white printed page.

## Context Diagram

```mermaid
flowchart LR
    Patient[Patient]
    Clinician[Clinician]
    Admin[Administrator]
    Frontend[Web Frontend]
    Backend[Backend API]
    Database[(PostgreSQL Database)]

    Patient -->|Submit reports and view status| Frontend
    Clinician -->|Review patients and alerts| Frontend
    Admin -->|Manage users and assignments| Frontend

    Frontend -->|Send API requests| Backend
    Backend -->|Return data and decisions| Frontend
    Backend -->|Store and retrieve records| Database
```

## Data Flow Diagram

```mermaid
flowchart TD
    A[Patient enters symptoms and vitals]
    B[Frontend validates form]
    C[Backend receives symptom report]
    D[Read patient context and assignment data]
    E[Run risk classification]
    F[Run trend analysis]
    G[Update report and patient status]
    H{Is an alert needed?}
    I[Create alert record]
    J[Show updated status to patient]
    K[Show alert on clinician dashboard]
    L[(Database)]

    A --> B
    B --> C
    C --> D
    D --> E
    E --> F
    F --> G
    G --> H
    C --> L
    D --> L
    G --> L
    H -->|Yes| I
    I --> L
    H -->|No| J
    I --> K
    G --> J
```
